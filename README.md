# Upgrader — сборка персональных компьютеров

![GitHub Actions](https://github.com/klaaantyyy/upgrader-web/actions/workflows/deploy.yml/badge.svg?branch=main)

**Upgrader** — веб-сайт мастерской по подбору комплектующих и сборке персональных компьютеров на заказ. Проект представляет собой адаптивный лендинг с информацией об услугах, готовых конфигурациях, примерами работ и возможностью сравнения компьютерных сборок.

🌐 **Демо:** [Открыть сайт на GitHub Pages](https://klaaantyyy.github.io/upgrader-web/)

---

## О проекте

Upgrader — сайт сервиса, специализирующегося на подборе совместимых комплектующих и сборке персональных компьютеров с учётом потребностей и бюджета заказчика.

Основная задача проекта — предоставить пользователю удобный интерфейс для ознакомления с услугами мастерской, просмотра готовых конфигураций и сравнения характеристик различных сборок.

Проект разработан с использованием HTML, CSS и JavaScript без применения тяжёлых frontend-фреймворков.

## Возможности

- **Информация о мастерской** — описание компании, её преимуществ и предоставляемых услуг.
- **Готовые конфигурации** — просмотр вариантов сборок персональных компьютеров с указанием основных характеристик и стоимости.
- **Слайдер конфигураций** — интерактивное переключение между представленными сборками.
- **Сравнение конфигураций** — выбор нескольких сборок и сопоставление их характеристик.
- **Галерея работ** — фотографии готовых компьютеров и примеров сборок.
- **Отзывы и часто задаваемые вопросы** — дополнительная информация для потенциальных клиентов.
- **Форма обратной связи** — интерфейс для оформления заявки.
- **Адаптивный дизайн** — корректное отображение сайта на компьютерах и мобильных устройствах.

## Локальный запуск

Проект не требует установки зависимостей или сборки.

1. Клонируйте репозиторий:

```bash
git clone https://github.com/klaaantyyy/upgrader-web.git
```

2. Перейдите в директорию проекта:

```bash
cd upgrader-web
```

3. Откройте `index.html` в браузере.

Для удобной локальной разработки можно использовать расширение Live Server в Visual Studio Code.

## CI/CD и автоматическое развёртывание

Для автоматизации проверки и публикации проекта используется GitHub Actions.

При каждом `push` в ветку `main` автоматически запускается workflow, описанный в файле:

```text
.github/workflows/deploy.yml
```

Пайплайн состоит из трех последовательных этапов.

### 1. Validate website

Перед публикацией выполняется проверка проекта с помощью Python-скрипта:

```text
scripts/check_site.py
```

Скрипт проверяет наличие основного HTML-файла и существование локальных ресурсов, на которые ссылается HTML-разметка.

Если обнаружены отсутствующие файлы или некорректные пути, проверка завершается с ошибкой, а публикация не запускается.

### 2. Validate HTML markup

Выполняется проверка html разметки согласно правилам, заданным в `.htmlhintrc`

### 3. Deploy website

После успешного завершения проверки выполняется автоматическая публикация проекта на GitHub Pages.

Для этого используются следующие GitHub Actions:

- `actions/checkout` — получение исходного кода репозитория;
- `actions/configure-pages` — настройка публикации через GitHub Pages;
- `actions/upload-pages-artifact` — подготовка файлов сайта к публикации;
- `actions/deploy-pages` — развёртывание сайта.

Публикация выполняется автоматически, без необходимости вручную загружать файлы на хостинг.
