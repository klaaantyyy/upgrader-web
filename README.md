# Upgrader — Landing Page

Лендинг мастерской сборки ПК **Upgrader**

## Структура проекта

```
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Описание

Адаптивный одностраничный сайт для мастерской по сборке компьютеров. Содержит разделы:

- **Hero** — приветственный экран с призывом к действию
- **О нас** — информация о мастерской
- **Преимущества** — ключевые особенности сервиса
- **Услуги и цены** — три тарифа: базовая сборка, под ключ, апгрейд
- **Конфигурации** — 6 готовых сборок под разные задачи
- **Наши работы и отзывы** — галерея фото, сводный рейтинг, отзывы клиентов
- **FAQ** — ответы на частые вопросы
- **Контакты и форма заявки** — контакты мастерской, интерактивная форма

## Технологии

- **HTML5** — семантическая разметка, микроразметка Schema.org (JSON-LD)
- **CSS3** — кастомные свойства, Grid/Flexbox, адаптивность, анимации
- **Vanilla JS** — мобильное меню, скролл-шпион, работа с формой

## Особенности

- Полностью доступный интерфейс (skip-link, focus-visible, ARIA)
- Поддержка `prefers-reduced-motion`
- Валидация формы на клиенте с кастомными сообщениями
- Передача выбранной конфигурации в форму через `data-` атрибуты
- Никаких внешних зависимостей кроме шрифта Manrope (Google Fonts)

## Запуск

Откройте `index.html` в браузере. Для корректной работы форм и путей к ресурсам рекомендуется раздавать через локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (npx serve)
npx serve
```

Затем откройте `http://localhost:8000`
